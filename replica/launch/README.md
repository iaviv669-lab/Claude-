# Launch: skipped (personal use)

Scope chosen at recon: **personal use**, no billing, no store listing. So this step produced no
landing page, pricing or store listing. Building them would be work with no user.

If you decide to publish Ironrow later, run `/replica-launch` again and do these first:

1. Finish the name checks marked "to run" in `../brand.md` (trademark, domain, Play, handles), and
   get a trademark lawyer's search before spending money on the name.
2. Replace the placeholder icon using the logo brief in `../brand.md`.
3. Write a privacy policy. Easy here: no account, no server, no analytics; data stays on the
   device. Say so plainly.
4. Pricing: none of the original's reviewers in our sample complained about price (`../fixes.md`),
   and an on-device app has almost no running cost, so a one-time price or free is the honest model.
5. Store listing: lead with the fixes (instant save, no account, CSV import, works offline), never
   the original's name; check with `listing.py`. Apple's guideline 4.1 (copycats) applies.
6. Native store apps need a wrapper (Capacitor) or a rewrite; the PWA can ship on the web as-is.

No fake proof, ever: no invented testimonials, ratings or user counts, and no reviewer quotes.
